# V6.3 全面对标 — Codex(对话体验) + DSHA(功能扩展)

> 2026-11-01 老板指令: "全面升级重构UI更加优美更加智能对话体验全面对标Codex功能扩展全面对标DSHA"

## Codex 对话体验精髓(落地项)
1. **单列呼吸排版**: 消息流内容最大宽度限制(640dp), 大屏不拉满, 居中呼吸感
2. **斜杠命令智能化**: 输入 "/" 弹出命令菜单(/compact /clear /model /skills /mcp), 键盘过滤, 点击执行
3. **工具卡紧凑 diff 风**: 命令等宽字体+成败状态点+耗时, 一行摘要
4. **底部状态行**: 模型名+上下文水位%+会话状态, 常驻输入框下方
5. **中性色系**: surfaceContainer 层次, 少量 primary 强调

## DSHA 功能扩展精髓(落地项)
1. **会话时间分组**: SessionsOverlay 按 今天/昨天/更早 分组(V6 遗留)
2. **浮窗快捷会话直发**: FloatingHub 面板加输入框, 直接 sendPrompt 不切 APP
3. **插件详情页**: 点插件卡展开完整 manifest(工具/参数/命令模板)
4. 浮窗 HUD 实时(Token/工具数)

## 不做(本轮范围外,防上下文爆炸)
- 设备镜像浮窗(需 screenrecord 管线, 单独一轮)
- inline approval(需 agent 协议改动)
- diff 补丁渲染(需输出格式协议)
