# 壳识别与脱壳路线

## 何时用
样本确认有壳/加固, 需要选择脱壳路线。

## 路线决策表
| 壳特征 | 首选路线 |
|--------|----------|
| 360加固(libjiagu) | 运行时脱壳(dump真身dex) 或 so重加密过签 |
| 梆梆/腾讯 | frida-dexdump 内存dump |
| 自研二进制壳(.sh包装) | unidbg零基址加载 + GOT重建 |
| 网络验证壳 | 仿真拆包 + 验证服务器响应oracle |

## 工具组合
run_shell(readelf -d) → mcpc(decompile 入口) → frida/ptrace 按路线

## 注意
- "保护还原"优先于"行为绕过"(产出可分析物 > 改行为)
- 脱壳产物要过 DTC 体检(壳残留检测)
