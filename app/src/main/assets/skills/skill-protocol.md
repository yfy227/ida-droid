# 协议还原方法

## 何时用
APP 网络协议逆向(签名/加密/风控字段)。

## 流程
1. **分层抓包**: 先明确层(HTTP body 层 / 自定义 TCP 层 / TLS 下层)
2. **定位加密函数**: 从 native 库 export/JNI 注册表 + 字符串线索(md5/aes 常量)
3. **密钥矩阵**: 静态密钥 + 动态密钥(设备指纹派生) 分开列
4. **签名公式还原**: 输入排序规则 + 拼接格式 + hash 链, 逐字段 oracle 验证

## 验证
- 每个字段用差分法验证(改一个输入看输出哪段变)
- 公式最终要用本地实现+线上发包双确认
